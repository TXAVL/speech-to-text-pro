# 🎙️ SPEECH TO TEXT PRO (Whisper AI, CapCut & Gemini)

> **Hệ thống chuyển đổi giọng nói & âm thanh thành văn bản siêu tốc**, tích hợp trí tuệ nhân tạo hàng đầu thế giới (Whisper Large v3, Google Gemini, CapCut Subtitle). Hỗ trợ xuất phụ đề chuẩn video và chia sẻ dùng trên điện thoại không cần cài đặt.

---

## 📸 Điểm Nổi Bật Dành Cho Bạn

* ⚡ **Siêu Tốc (~1 - 2 Giây)**: Chuyển đổi đoạn âm thanh 5 - 10 phút gần như ngay lập tức với Groq Whisper Large v3 hoặc Web Speech Local AI (không cần Key).
* 🗣️ **CapCut Text-to-Speech (TTS) Studio**: Chuyển ngược văn bản thành giọng đọc CapCut / TikTok siêu hot (Nhỏ Ngọt Ngào, Cô Gái Hoạt Ngôn, Nam Trầm, Thanh Niên Tự Tin, v.v.), nghe thử và tải file MP3 tức thì!
* 🎬 **Xuất Phụ Đề Chuẩn CapCut / TikTok**: Tự động ngắt câu ngắn vừa nhịp đọc, bấm 1 nút tải file `.SRT` nhập thẳng vào CapCut dựng video.
* 🧠 **AI Thông Minh**: Tự động chấm câu, phân biệt từng người nói (*Speaker 1, Speaker 2*), tóm tắt ý chính và dịch thuật đa ngôn ngữ.
* 📱 **Dùng Trên Điện Thoại Dễ Dàng**: Tự động tạo link HTTPS và **Mã QR Code**, chỉ cần quét bằng camera điện thoại là dùng được ngay.
* 🔒 **Bảo Mật 100%**: File âm thanh và API Key lưu trực tiếp trên máy của bạn, không lo lộ dữ liệu.

## 🚀 Hướng Dẫn Sử Dụng (Dành Cho Người Mới)

### Bước 1: Khởi động chương trình
* Chỉ cần **nhấp đúp chuột vào file `start.bat`**.
* Màn hình trình duyệt sẽ tự động mở lên tại địa chỉ: `http://localhost:3000`.

### Bước 2: Nhập API Key (Hoặc Dùng Miễn Phí Không Cần Key)
Bạn có thể chọn **Web Speech Local AI** để dùng ngay 100% không cần key, hoặc bấm vào nút **"Cấu hình API"** ở góc phải trên cùng để kích hoạt các mô hình AI mới nhất 2026 (Keys lưu an toàn trên trình duyệt của bạn):
1. **Web Speech Local AI (Mới - Không Cần Key)**:
   * Chạy trực tiếp trên trình duyệt bằng AI máy tính, hoàn toàn miễn phí, bảo mật riêng tư 100%.
2. **Groq Whisper Large v3 Turbo (Mới nhất 2026 - Siêu tốc & Miễn phí 100%)**:
   * Truy cập: [console.groq.com/keys](https://console.groq.com/keys)
   * Đăng ký miễn phí ➔ Copy API key và dán vào web. Tốc độ chuyển đổi 216x (file 5 phút chỉ mất 1-2 giây).
3. **Google Gemini 2.5 Flash Audio (Mới nhất 2026 - Miễn phí 100%)**:
   * Truy cập: [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
   * Đăng ký miễn phí tại Google AI Studio ➔ Nhận miễn phí 1,500 lượt gọi/ngày. Tự động ngắt dấu câu chuẩn xác, phân biệt người nói và tóm tắt AI.
4. **CapCut Subtitle AI & CapCut TTS Studio**:
   * Tối ưu nhịp ngắt phụ đề ngắn cho video ngắn TikTok/Reels/Shorts kèm studio tạo giọng đọc AI CapCut tiếng Việt chuẩn.
5. **OpenAI GPT-4o Transcribe (Mới nhất 2026)**:
   * Kiến trúc nhận diện giọng nói thế hệ mới từ OpenAI, tỉ lệ lỗi WER thấp vượt trội so với Whisper-1 cũ (tự động fallback Whisper-1).

### Bước 3: Chọn cách nhập âm thanh
Bạn có 3 lựa chọn cực kỳ thuận tiện:
1. **Kéo thả / Tải lên**: Kéo file âm thanh (MP3, WAV, M4A, AAC, OGG...) hoặc video (MP4, MKV) vào ô.
2. **Dán link URL**: Dán link file âm thanh trực tiếp từ Internet vào.
3. **Thu âm Micro**: Nhấn vào nút Micro để nói trực tiếp, có sóng âm và đồng hồ đếm giờ.

*(Giới hạn: Tối đa 10 phút hoặc 30MB mỗi file - phù hợp cho hầu hết video TikTok/Reels, podcast, phỏng vấn, ghi âm cuộc họp).*

### Bước 4: Bấm "Bắt đầu chuyển đổi ngay"
* Chọn mô hình AI mong muốn (ví dụ **Web Speech Local AI**, **Whisper Large v3 Turbo**, **Gemini 2.5 Flash Audio**, hoặc **CapCut Subtitle AI**).
* Chờ 1 - 3 giây, toàn bộ nội dung lời nói sẽ hiện ra chuẩn xác 99%!

## 🎬 Cách Xuất Phụ Đề Đưa Vào CapCut (TikTok / Shorts / Reels)

1. Chọn mô hình **CapCut Subtitle AI** khi chuyển đổi (hệ thống sẽ tự động ngắt các dòng ngắn dưới 8 từ theo nhịp đọc).
2. Khi văn bản hiện ra, bấm vào nút **"Tải về"** ➔ Chọn **Phụ đề CapCut/Premiere (.SRT)**.
3. Mở phần mềm **CapCut** trên máy tính hoặc điện thoại:
   * Vào mục **Văn bản (Text)** ➔ Chọn **Nhập phụ đề (Local Subtitles / Import SRT)**.
   * Chọn file `.SRT` vừa tải về. Toàn bộ chữ sẽ tự động khớp đúng từng giây với video của bạn!

3. Bạn có thể thu âm trực tiếp bằng micro điện thoại hoặc tải file ghi âm từ điện thoại lên để chuyển đổi bất cứ lúc nào!

## 🌐 Hướng Dẫn Đưa Lên Hosting & Gắn Tên Miền Riêng (Domain)

### Cách 1: Lấy Tên Miền Miễn Phí `*.workers.dev` (Cloudflare Workers) ⭐ Khuyên dùng
Cloudflare cung cấp sẵn tên miền con miễn phí dạng **`https://ten-ban.workers.dev`** cực nhanh và có sẵn chứng chỉ bảo mật HTTPS:
1. Đăng nhập [dash.cloudflare.com](https://dash.cloudflare.com) ➔ Chọn mục **Workers & Pages**.
2. Đặt tên subdomain miễn phí của bạn (ví dụ: `myvoice.workers.dev`).
3. **Cách triển khai 1 dòng lệnh**:
   * Mở terminal tại thư mục dự án và chạy:
     ```powershell
     npx wrangler deploy
     ```
   * Trình duyệt sẽ mở ra để bạn xác nhận đăng nhập Cloudflare ➔ Hệ thống sẽ tự động đưa toàn bộ web lên link: **`https://speech-to-text-pro.<subdomain>.workers.dev`**.
4. **Hoặc làm Proxy cố định cho máy tính**:
   * Mỗi khi chạy `start.bat` có link `trycloudflare.com`, bạn có thể gán link đó vào `TARGET_BACKEND` trong Worker để luôn có 1 domain `workers.dev` cố định truy cập về máy nhà.

### Cách 2: Gắn Tên Miền Riêng (Custom Domain) Không Tốn Tiền Host
1. Thêm tên miền của bạn vào [Cloudflare](https://dash.cloudflare.com).
2. Vào **Zero Trust** ➔ **Networks** ➔ **Tunnels** ➔ Tạo Tunnel mới.
3. Chọn dịch vụ chuyển tiếp về: `http://localhost:3000`.
4. Điền tên miền con bạn muốn (ví dụ: `voice.tenmien.com`).
5. Xong! Web của bạn trên máy tính sẽ tự động chạy dưới tên miền riêng qua giao thức HTTPS có ổ khóa xanh.

### Cách 2: Triển khai lên Hosting Cloud (Render / Railway / VPS)
Dự án đã tích hợp sẵn file `Dockerfile` và `package.json` chuẩn sản xuất:
1. Đưa code này lên **GitHub** cá nhân của bạn (xem hướng dẫn Git bên dưới).
2. Vào [Render.com](https://render.com) hoặc [Railway.app](https://railway.app):
   * Chọn **New Web Service** ➔ Kết nối tài khoản GitHub và chọn kho lưu trữ này.
   * Chọn môi trường: **Node** (hoặc **Docker**).
   * Lệnh khởi động: `npm start`.
   * Thêm các biến môi trường (Environment Variables) nếu muốn: `GROQ_API_KEY`, `GEMINI_API_KEY`, `PORT=3000`.
3. Trong phần **Custom Domains** của Render/Railway:
   * Nhập tên miền riêng của bạn.
   * Vào trang quản lý tên miền (như Cloudflare, Namecheap, iNet, MatBao...) thêm bản ghi **CNAME** trỏ về địa chỉ do Render/Railway cung cấp.
